MS2 (Montecarlo Scarface 2) is a chess analysis program based on the Monte Carlo method, utilizing the Stockfish 2.2 engine.
Users can input the position to be analyzed either via FEN string or by setting up the board using the graphical interface. 
The program runs multiple games starting from the given position, displaying the results—including the number of wins, losses,
and draws—and saving these statistics to a `log.txt` file. 
Moves are selected randomly, subject to configurable parameters (such as a range for move consideration based on the engine's evaluation).
It is also possible to limit the duration of each game to a specific number of moves (the program does not play out the entire game,
but rather a set number of moves).
